# History

Review and hardware-test records written for the code before the 2.0
rewrite, kept because they say what each owner checked on their own
headphones. File names in them (`sony-bridge`, `Model.js`, `DeviceFollower.qml`,
the probes in `tools/`) are the old layout: each `<brand>-bridge` is now
`bridges/brands/<brand>.py`, `Model.js` is `lib/`, `DeviceFollower.qml` is
`Headset.qml`, and the probes were replaced by `tools/trace`. The frozen
sessions those owners recorded are still `tests/pins/`, unchanged.
